# Security Web Lab

HTML / JavaScript / PHP を使って、
脆弱なWebアプリから段階的に堅牢化する学習用リポジトリです。

## 学習環境

- Windows 11
- VMware
- Ubuntu Server
- Tera Term
- PHP
- JavaScript
- HTML

## 今後追加予定

- HTTP解析
- Wireshark
- Suricata
- 検知ルール
- ログ分析
- ELK連携

## 方針

- 実IPや実ログは掲載しない
- サンプル値はダミー値を使用
- 脆弱な状態から段階的に改善する
