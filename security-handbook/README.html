CTFで学んだWeb攻撃の原理を、HTTP通信 → 解釈される言語 → 脆弱性が生まれる境界 → 観測方法 → 対策 → 根拠の順に整理した学習資料です。単なるコマンド集ではなく「なぜ成立するのか」を重視します。

使用条件：自分で管理する検証環境、または明示的に許可されたCTFのみで実行してください。記載のホスト名、DB名、利用者名、認証情報は架空です。演習環境で得た実IP、Cookie、パスワード、フラグ、シェルファイル等は公開しません。

要点早見表

技術 根本原因 代表的な対策 よくある誤解
SQLi 入力がSQL構造の一部になる パラメータ化・識別子の許可リスト prepareという文字があるだけで安全
XSS 信頼できない値が実行可能なHTML/JSとして扱われる 出力文脈別エンコード・安全なDOM API DB保存時のSQLi対策でXSSも防げる
OSコマンド注入 入力がシェル構造の一部になる OSコマンドをやめて専用API $_GETへ代入すれば安全
PHPランタイム アプリコード外の実行環境に欠陥 修正版の適用、被害縮小策 PDO::prepare()でPHPエンジンのRCEも防げる

手元で安全に確かめる

examples/ に防御実装だけを置きました。実行する場合もローカル/隔離環境で、PHP CLIおよび必要な拡張を確認してください。攻撃用Webシェルや実サーバーの抽出データは収録していません。
