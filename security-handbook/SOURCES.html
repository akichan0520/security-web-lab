一次資料・エビデンス台帳

確認日：2026-10-24（参照先の内容は将来変更され得る）

各章には本文中にも対応する公式リンクを入れている。この台帳は「どの主張を何で裏付けたか」をまとめる。一般論を個別のCTF環境での事実と混同しないこと。

ID 根拠資料（原典中心） 裏付ける要点 適用範囲と限界
S01 OWASP SQL Injection Prevention パラメータ化クエリ、識別子の許可リスト、最小権限 個々のPDOコードの実装品質までは保証しない
S02 PHP PDO::prepare prepare、プレースホルダーとデータ値の区別、PDO実装注意 DBドライバー、エミュレーション設定差に注意

S04 sqlmap Usage -r, -p, --technique, --string, --os-shell, ファイル操作オプション 機能は権限・DB仕様に依存
S05 PortSwigger Burp HTTP history リクエスト・レスポンス観測 Burpの版でUIが変わり得る
S06 PortSwigger Repeater 手動送信・比較 許可された環境に限定
S07 MySQL server system variables secure_file_priv, datadir 等の設定 MySQL系列/版に注意
S08 MySQL SELECT INTO OUTFILE/DUMPFILE、制限、既存ファイル 実際のOS権限は別
S09 MySQL security against attackers DB権限・安全なファイル配置 設計指針であり個別製品の安全保証ではない
S10 OWASP Cross Site Scripting Prevention 文脈別エンコード、安全なsink JS・URL文脈には個別ルール
S11 PortSwigger XSS Reflected/Stored/DOMの定義 複合パターンもある
S12 OWASP OS Command Injection Defense シェル排除・引数制御・許可リスト 実行権限やOSで細部が変わる
S13 PHP Validation Filters FILTER_VALIDATE_DOMAIN、FILTER_FLAG_HOSTNAME 形式検証はアクセス可否の許可ではない
S14 PHP dns_get_record DNSレコード取得API リゾルバ/内部DNSの制約が残る
S15 OWASP SSRF Prevention ドメイン検証だけでは安全を保証しない DNSリバインディング等は構成依存
S16 OWASP Error Handling 例外表示で内部情報を漏らさない 診断ログは別途保護が必要
S17 PHP公式 News 2026-10-21 PHP2Shellの修正版の系列と緊急性 修正版は更新基準日当時の情報
S18 PHP GHSA CVE-2026-109618 OOM起因のRCE可能性 実際の成立条件は構成による
S19 PHP GHSA CVE-2026-109619 状態残留に関係するRCE可能性 同上

S22 OWASP Authorization SQLi対策ができても認可不備は残る プロジェクトごとに認可モデルが必要

「エビデンスあり」の扱い

  • 仕様の根拠：公式マニュアル・CVEアドバイザリなどで一般原理を説明できる。
  • CTFでの観測の根拠：手元のHTTPレスポンス、コマンド表示、スクリーンショット等。公開版には秘匿値を残さない。
  • 因果関係の根拠：真/偽・修正前後・通常入力などの比較が必要。単なるHTTP500やNo outputは単独の証明ではない。
  • 注意：過去の会話から作った説明には、仮のパスや例示SQLが含まれる。本ノートは実端末・実DBの検証結果を保証しない。
